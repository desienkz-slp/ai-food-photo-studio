# AI Food Photography Studio

Proyek aplikasi web untuk membantu meningkatkan fotografi makanan dan minuman dengan mengutamakan keaslian produk. Implementasi aplikasi belum dimulai; repository ini hanya berisi persiapan dan rencana kerja.

## Prinsip produk

- File sumber tidak ditimpa; setiap output memiliki jejak versi.
- Pengguna mengendalikan pilihan latar per foto dan meninjau hasil sebelum ekspor final.
- Perubahan generatif tidak boleh mengubah area produk yang dilindungi dalam mode balanced.
- Kualitas segmentasi dan fidelity perlu dibuktikan melalui benchmark dan review manusia.
- Penggunaan provider eksternal dan transfer foto memerlukan persetujuan tersendiri.

## Status

Persiapan: baca `docs/ROADMAP.md` dan `docs/WORKFLOW.md`. Tidak ada kode aplikasi, deployment, atau hasil benchmark dalam repository ini.
